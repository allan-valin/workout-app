### Found and fixed during this pass

- Session list-mode top bar: a long workout name wrapped to two lines and pushed the
  "elapsed / estimated" caption out of the fixed-height bar. Imported workouts now carry a
  "(plan abbrev dd/MM)" tag, so long names became the norm — title is now one line,
  ellipsized, titleMedium. FIXED + verified.
- `PlanTransfer.abbreviate` split on `[\s\-_/]+`, so a plan already ending in "(2)"
  produced the tag "ScoT4F(" (stray paren). Now splits on any non-letter/digit run →
  "ScoT4F3". FIXED + verified. (Emulator test data created before the fix still shows the
  old tag; harmless.)
